# CyberAssetIQ Investor Demo Script (v24)

## Demo promise

**CyberAssetIQ gives SMEs a single asset view across managed endpoints, unmanaged network devices, and dark-web exposure — then explains what matters first.**

---

## 1) Open the dashboard

**Say:**
"Most SME tools either show endpoint telemetry or run a network scan. We correlate both into one asset record and surface the risk in plain English."

**Show:**
- Total assets
- Average risk score
- Compliance score
- Dark web links
- Shadow IT count

---

## 2) Queue a silent scan

**Action:** Queue a silent scan from the Overview page.

**Say:**
"The platform can silently orchestrate scans through the agent. That gives us fresh posture, software, and local findings without the user touching the endpoint."

**Show:**
- Status changing to queued / running
- Recent scan jobs table updating

---

## 3) Open the unified asset view

**Say:**
"This is the single pane of glass. If the same device is seen by the agent and by the network scanner, we merge those records instead of duplicating them."

**Show:**
- Source badges (`agent`, `network`)
- Managed vs unmanaged
- Risk score per asset
- Compliance score per asset

**Point out:**
- Match confidence
- Dark web findings count
- Open CVE count

---

## 4) Explain one risky asset

**Action:** Click the highest-risk asset.

**Say:**
"We do not just say an asset is risky. We show why: exposed services, weak posture, vulnerability count, and any linked identity exposure."

**Show in detail panel:**
- Risk score
- Top risk factors
- Recommended actions
- Dark web link if present
- Software inventory snippet

---

## 5) Run network discovery

**Action:** Discover unmanaged assets from the Network tab.

**Say:**
"This is important for SMEs because the riskiest device is often the one no one knew was there."

**Show:**
- New discovered host
- Open ports
- It appears in Unified Assets as `managed = No`
- Risk increases because it is shadow IT

---

## 6) Run dark web matching

**Action:** Add a watchlist and run exposure matching.

**Say:**
"Now we connect identity exposure back to the environment. A leaked email or domain is not just a text match — it increases asset risk where we can correlate it."

**Show:**
- Exposure finding
- Linked assets / link strategy
- Risk jump on the affected asset
- Storyline card on the Overview tab

---

## 7) Close with the wedge

**Say:**
"Our wedge is not another scanner. It is clarity for SMEs: one asset graph, simple prioritisation, and actionability without enterprise complexity."

## 30-second close

"CyberAssetIQ helps SMEs answer four questions immediately: what do I have, what is unmanaged, what is exposed, and what do I fix first? This MVP proves the correlation engine, the risk layer, and the investor demo flow are already working together."
